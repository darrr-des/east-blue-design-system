How Assessment Reports Are Built
01 — Source
Edit a component file
Each component has its own file in assessment-src/components/. Edit only that file to update its assessment.
02 — Build
Run the build script
Run node assessment-src/build.js to assemble all component files into the final HTML report.
03 — Add
New component
Drop a new .html file into assessment-src/components/ and rebuild. It's automatically added to the nav and summary.
04 — Ship
Push to GitHub
Commit and push. The updated report is immediately live on GitHub Pages at the repo URL.
